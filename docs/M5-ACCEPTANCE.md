## 本 milestone 的最小范围

- 家庭有效成员可以创建、编辑、停用和重新启用自定义模板；
- 自定义字段支持数字、简短文字和单选；
- 字段、单选项可以停用，已经进入记录快照的结构不能破坏性删除或改类型；
- 一条记录最多附加 3 个简短临时字段；
- 首次保存后，记录所属人、模板和字段结构锁定；
- 模板改名或停用字段不改变旧记录的名称和字段快照；
- 记录支持内容编辑，并通过 `revision` 防止旧版本静默覆盖；
- 记录使用软删除；普通时间线隐藏，最小恢复入口可以恢复。

## 简化决定

- M5 不建立模板版本历史表；记录自己的模板与字段快照就是历史保护；
- 模板列表数据量很小，云函数内存排序，不为此引入额外数据库索引；
- 不建立完整回收站，只提供“已删除记录”最小恢复页；
- 临时字段只支持简短文字且最多 3 个；
- MVP 中字段一旦保存便锁定类型；需要不同类型时新增字段并停用旧字段，避免把历史语义改掉；
- 系统模板结构仍由代码维护，家庭只管理自定义模板。
