状态：自动验收完成，等待双账号真机验收

## 本 milestone 的最小范围

- 每个用户全局最多一份健康档案；
- 档案只保存糖尿病状态、高血压状态和选填的高血压分级；
- 本人始终可以查看和修改自己的档案；
- 同一家庭的有效成员可以互相查看档案；
- 档案所有者按家庭开启或关闭代管；
- 只有获授权家庭的有效成员可以代为修改；
- 管理员没有额外档案权限；
- 使用 `revision` 防止旧页面静默覆盖新修改。

## 开发环境部署提示

当前微信开发者工具版本完整部署云函数时可能漏掉 `src` 子目录。部署顺序固定为：

1. 完整部署并选择云端安装依赖；
2. 再对同一云函数增量部署 `src` 目录；
3. 用模拟器或真机调用一次公开动作确认远端入口。

4. B 重新开启代管，A 修改并保存成功；
5. 再次关闭代管，确认 A 即使是管理员也不能继续修改。
