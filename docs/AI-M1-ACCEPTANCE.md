# AI-M1 验收：永久令牌、复制和访问历史

AI-M1 已把 AI-M0 的关闭态骨架扩展为可由小程序用户管理的永久令牌系统。真实健康数据的读取仍属于 AI-M2；本阶段有效令牌调用 `getContext` 会稳定返回 `SERVICE_NOT_READY`，同时形成一条脱敏访问历史。

## 已完成

- “我和家庭 → 数据与连接 → AI 与外部应用”管理入口；
- 创建、列出、重新复制和永久撤销多枚令牌；
- 令牌格式为 `fhp_<tokenId>.<256 位随机 secret>`；
- 使用 HMAC-SHA256 摘要完成恒定时间认证比较；
- 使用 AES-256-GCM 加密保存可重新复制的 secret；
- 主密钥只存放在云函数环境变量，不进入代码、Git 或数据库；
- 创建请求按 `requestId` 幂等，并用唯一索引防止并发重复；
- 撤销事务同时清除密文、nonce、认证标签和认证摘要；
- 列表展示最后访问时间，详情展示最近 20 次脱敏调用；
- 访问历史不保存令牌、健康数值、备注或完整请求体；
- 动态生成包含 HTTPS 地址、令牌和 curl 说明的 Skill，不把 Skill 入库；
- 复制令牌或 Skill 前显示永久凭证风险确认；
- 公网入口只接受 `POST /v1/action`，明文 HTTP 被拒绝；
- 鉴权、业务或历史写入异常只返回统一安全错误，不暴露内部异常或已读取数据。

## 云端资源

开发环境：`cloud1-d0gf9cdxd89dafde0`

HTTPS Base URL：

```text
https://cloud1-d0gf9cdxd89dafde0-1389722065.ap-shanghai.app.tcloudbase.com
```

HTTP 访问路由：

```text
POST /v1/action -> external-access-api
```

路由关闭 CloudBase 自带身份认证，由应用自己的 Bearer 令牌认证；同时启用网关 IP 限频。无效或已撤销令牌统一返回 `401 / INVALID_CREDENTIAL`。

新增集合：

- `external_access_tokens`：令牌摘要、密文和管理状态；
- `external_access_events`：脱敏访问摘要。

两个集合均已明确设置为 `ADMINONLY`，小程序客户端不能直接读取、创建、修改或删除其中的文档，只能通过云函数的窄接口操作。

已配置的云函数环境变量名称：

- `EXTERNAL_ACCESS_MASTER_KEY`；
- `EXTERNAL_ACCESS_KEY_VERSION`；
- `EXTERNAL_ACCESS_BASE_URL`；
- `EXTERNAL_ACCESS_ENABLED`。

环境变量的值不得写入文档、日志或仓库。部署代码时应使用合并模式保留线上变量。

## 2026-08-19 开发环境实测

已完成一枚临时验收令牌的完整生命周期：

1. 在小程序页面创建令牌；
2. 刷新小程序，确认可以从云端重新复制令牌和 Skill；
3. 确认 Skill 使用上述 HTTPS Base URL，并包含同一枚令牌；
4. 使用有效令牌调用 `getContext`，得到 `503 / SERVICE_NOT_READY`；
5. 页面访问历史出现“读取家庭信息 / 功能仍在接入”，历史中不含 token；
6. 永久撤销令牌后，重新复制返回 `TOKEN_REVOKED`；
7. 同一旧令牌再次调用公网入口，得到 `401 / INVALID_CREDENTIAL`。

临时验收令牌已经撤销，只保留不含可用 secret 的摘要和一条脱敏历史。

## 人类验收

1. 打开“我和家庭”，进入“AI 与外部应用”；
2. 输入名称、勾选风险确认并创建令牌；
3. 测试“复制令牌”和“复制 Skill”的二次确认；
4. 关闭并重新进入小程序，确认详情仍可复制；
5. 永久撤销后，确认复制按钮消失，令牌进入“已撤销”；
6. 展开详情，确认最近访问只显示时间、动作、范围和结果，不显示健康值或令牌。

## 已知依赖风险

`wx-server-sdk 4.0.2` 是当前稳定版，但其官方传递依赖仍被 `npm audit` 标记为 5 个高风险和 1 个中风险问题。当前函数没有把用户输入作为外部 URL、代理配置或动态数据库字段路径使用，已经降低这些公告对应的可利用面；不能使用 `npm audit fix --force` 建议的旧版 SDK 降级。后续应在微信/CloudBase 发布修复版后优先升级并重新审计。
