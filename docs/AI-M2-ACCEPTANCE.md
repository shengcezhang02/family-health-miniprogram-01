# AI-M2 验收：真实数据只读访问

AI-M2 已让永久令牌通过公网 HTTPS 接口读取真实的家庭、成员、模板、记录、一次性提醒和周期规则。写入、打卡、暂停、恢复和软删除仍不在本阶段开放。

## 当前权限边界

- 令牌代表创建它的用户，而不是一个独立的家庭成员；
- 只要令牌所有者仍是某个家庭的有效成员，令牌就能读取该家庭所有有效成员的日常健康数据；
- 不再要求同家庭其他成员逐人确认后才允许读取；
- 加入家庭时仍展示外部 AI 访问说明并要求明确勾选，用于事前告知和审计，但它不再充当读取接口的运行时开关；
- 令牌所有者退出家庭后，接口会实时拒绝访问该家庭；
- 令牌不能访问令牌所有者未加入的家庭；
- 永久撤销令牌后，公网接口立即拒绝该令牌。

## 已开放动作

- `getContext`：读取令牌所有者、可访问家庭、家庭成员和模板；
- `listTemplates`：读取指定家庭的系统模板和自定义模板；
- `listHealthItems`：按家庭、类型、所属人、模板和时间范围分页读取健康事项；
- `getHealthItem`：按 ID 读取单条记录、一次性提醒或周期规则。

读取结果不会返回已软删除事项。列表接口限制筛选字段、分页大小和游标格式，单条接口会再次验证事项所属家庭。

## 人类验收

1. 打开“我和家庭 → 数据与连接 → AI 与外部应用”；
2. 确认页面说明为“令牌所有者仍在家庭中即可访问同家庭成员”，不再显示等待成员确认；
3. 复制现有令牌或 Skill，让外部 AI 先调用 `getContext`；
4. 让 AI 分别读取本人和另一位家庭成员的记录，确认两者都成功；
5. 回到令牌详情，确认最近访问里出现对应动作和时间，且不显示健康值或令牌；
6. 如需验证边界，可撤销一枚临时令牌，再确认旧令牌得到 `401 / INVALID_CREDENTIAL`。
